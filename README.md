# Hub2gether landing page

Site vitrine statique pour présenter Hub2gether :

- Opportunité de marché B2B sport / entreprise
- Bénéfices pour les entreprises (gestion, coûts, engagement)
- Bénéfices pour les utilisateurs (networking, stats, paiements simplifiés)

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir : `http://localhost:8000`.
